# 今日のタスクを提案する

`electron/datas/outline.json`（アウトラインの保存データ）の未完了タスクから、今日取り組むタスクを選んで提案してください。データは読むだけで、ファイルの作成・変更はしません。

## 引数

引数：`$ARGUMENTS`

- 先頭が数字なら、提案する件数です（1〜20。省略時は5）。
- 残りがあれば、対象のタブ名です。省略時はアーカイブタブ以外の全タブが対象です。

## 手順

1. 次のコマンドで、未完了タスクの階層ツリーを取得します。タブ名の指定があれば、シングルクォートで囲んで引数に渡します。

   ```sh
   node scripts/outline_tree.mjs 'タブ名'
   ```

   タブが見つからないと表示されたら、表示されたタブ名の一覧を添えて、その旨だけを答えます。
2. 出力の先頭にある今日の日付をもとに、優先度を付けます。
   - 項目名やメモにある期限・日付（例：`11/20`、`明日`、`今週中`）が近いもの、過ぎているものを優先します。
   - 上位の階層（案件）を進めるのに必要な、具体的な作業（末端の項目）を選びます。親だけを選ばないでください。
   - `[x]` は完了済みだが未完了の子があることを示します。`✦` は前回の提案です。残っていれば、続けるかを判断します。
3. 指定された件数だけ選び、下の形式で答えます。

## 出力の形式

Markdownで、次の順に書きます。前置きや手順の説明は書きません。

```markdown
## 今日のタスク（YYYY-MM-DD）

1. **項目名**（親 › 親）
   - 理由：期限・階層上の位置などを1文で
2. ……

## ひとこと

全体の進め方を1〜2文で。
```

最後に必ず、提案した項目のidを1行に1つずつ、次のブロックで書きます。idはツリーの `〔id:…〕` の中身をそのまま使います。

````markdown
```focus-ids
id1
id2
```
````
