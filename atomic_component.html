color.htmlの背景の色味や重なったアイコンを、再利用できる部品として整理しました。色・形・文字・余白から、それらを組み合わせたUIまで、見本とCSSで説明します。

配色と背景 — Foundations

画像から取り出した深緑・茶色・白を中心に、ページ用の背景色・文字色・罫線色を加えています。背景はわずかに黄みを含む明るい色。白いカードを重ねると、面の違いが穏やかに見えます。

PAGE BACKGROUND · #F6F5EF

白い面を、やさしい背景に。

カードは #FFFFFF。輪郭は #DCE2D9 の1px線で区切ります。

説明文には落ち着いた緑がかった文字色を使い、ゆったりと行間を取ります。

Body copy / 14px / line-height 1.85 / Muted
#044523Color code / 21px / monospace

読みものと数値で、書体を使い分ける。

文章はOS標準のサンセリフを優先し、日本語はヒラギノやメイリオなどにフォールバックします。コード・数値には等幅書体を使い、文字と情報の役割を分けています。

body {
  color: var(--ink);
  font-family: -apple-system, BlinkMacSystemFont,
    "Helvetica Neue", "Hiragino Kaku Gothic ProN",
    "Noto Sans JP", Meiryo, sans-serif;
  line-height: 1.85;
}
code, output {
  font-family: ui-monospace, SFMono-Regular,
    Consolas, monospace;
}

書体の見え方は端末によって異なります。元ページでは外部Webフォントを読み込んでいません。720px以下ではH2を20pxに調整します。

  accent-color: var(--green);
}

リンクの「↓」「↗」は文字で表現しています。フォーカスの茶色い輪郭は、キーボードで現在の操作位置を見つけるための要素です。

部品を組み合わせる — Molecules

ここでは、色・文字・線・ボタンなどの小さな部品を「Atoms」、それらを組み合わせたまとまりを「Molecules」として整理しています。さらにヘッダーや配色セクションへと組み上げると、元ページの構成になります。

色面 ＋ ラベル ＋ コード ＋ ボタン

深緑 / Forest green

#044523

RGB(4, 69, 35) · 手前のピース

色カード：上の色面と下の情報面を接続。外側だけを9pxで丸め、ひとつのまとまりに見せています。

白い面 ＋ 画像 ＋ キャプション

画像フレーム：内側22px、外周16pxの角丸、1pxの罫線。資料では画像を最大240pxに縮小しています。
