使い始める

目的に合うHTMLを選んでください。下の資料リンクはすべて別タブで開きます。

業務定義 ↗→業務の流れ ↗→オブジェクト ↗→画面設計 ↗→単体テスト ↗

業務を整理し、必要な情報をまとめ、画面の表示・操作とテストへ具体化します。計画書とカレンダーは、各工程の計画・実施状況の整理に使います。

業務を整理する

業務定義シート ↗

business_definition_sheet.html

業務の目的・担当・入力情報・作業内容・成果物を整理し、業務ごとの定義シートを作成します。

使い方・機能：シートの追加・入力、ブラウザ内保存、JSON読み込み／書き出し、印刷・PDF。

業務シーケンス図 ↗

business_sequence.html

情報項目と担当のマトリクスに作業・帳票を置き、矢印でつないで業務の流れを整理します。

使い方・機能：図の編集、ブラウザ内保存、JSON読み込み／書き出し、印刷・PDF。

オブジェクト整理 ↗

object_model.html

オブジェクトの名前・プロパティ・操作を整理し、シングルとコレクションの表示項目・操作を設計します。

使い方・機能：オブジェクト・コレクションの編集、ブラウザ内保存、JSON読み込み／書き出し。

画面を設計・テストする

画面・機能設計書 ↗

screen_design_template.html

Web自動販売機を例に、画面一覧・遷移、オブジェクト、データ・権限、画面要素、操作、検証と結果を定義します。

使い方・機能：設計例を参照し、HTML内の内容を編集して自分のシステムの設計書に使います。見本の購入・保存は実行しません。

画面単体テストケース ↗

screen_unit_test.html

画面グループごとに「目的 → 前提 → ケース表」を読み、正常・バリデーション・異常を確認します。

使い方・機能：OK／NG・保留の記録、実績メモ、集計、ブラウザ内保存、結果のJSON書き出し。自動テストの実行ページではありません。

計画・スケジュールを整理する

スケジュール計画書 ↗

schedule_plan.html

プロジェクトの目的・マイルストーン・ガントチャート・WBS・体制・リスクをまとめます。

使い方・機能：HTML内の内容を編集して、プロジェクト計画・役割分担・進捗報告の資料に使います。

カレンダースケジュール ↗

calenderschedule.html

カレンダーに予定や工程を入力し、ガントチャートやマトリクスシーケンスで確認します。

使い方・機能：予定の追加・編集、表示切り替え、ブラウザ内保存。

デザインを参照・資料を作成する

カラーコードの説明 ↗

color.html

tome.jpgの代表色を使い、HEX・RGBの読み方と色の組み合わせを学びます。

使い方・機能：色見本、カラーコードのコピー、RGBスライダー。

デザイン要素の説明資料 ↗

atomic_component.html

背景色・重なった四角のアイコン・文字・ボタン・余白・角丸を、見本とCSSで確認します。

使い方・機能：共通デザインを再利用する時の参照資料。

説明資料の雛形 ↗

document_template.html

左に目次、右に本文を置いた説明資料を作成します。

使い方・機能：HTML内の見出し・本文・表・手順・コード例を差し替えて利用します。

編集と保存

  • 編集ツールのページ：業務定義シート・業務シーケンス図・オブジェクト整理・カレンダーは、画面内で内容を入力します。
  • 資料のページ：画面設計書・スケジュール計画書・説明資料の雛形は、HTML内の文章や表を書き換えて使います。
  • テストの記録：画面単体テストケースは、画面内で実施結果とメモを入力できます。
  • ブラウザ内の保存：データは端末間で自動共有されず、HTMLファイル自体にも書き戻されません。別のブラウザや保存場所では同じ記録を参照できない場合があります。
  • 書き出し：JSON機能があるページでは、受け渡しや控えに書き出しを使います。読み込み機能の有無は各ページのボタンを確認してください。

参照画像
