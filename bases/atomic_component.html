心地よさをつくる、

color.htmlの背景の色味や重なったアイコンを、再利用できる部品として整理しました。色・形・文字・余白から、それらを組み合わせたUIまで、見本とCSSで説明します。puzzlesの編集画面で使うアイコンや、フォーカス・選択・集中の意味も整理しています。

掲載する数値は元ページの実装値です。この資料自体のレイアウトには、説明用のスタイルを追加しています。

配色と背景 — Foundations

画像から取り出した深緑・茶色・白を中心に、ページ用の背景色・文字色・罫線色を加えています。背景はわずかに黄みを含む明るい色。白いカードを重ねると、面の違いが穏やかに見えます。

読みものと数値で、書体を使い分ける。

文章はOS標準のサンセリフを優先し、日本語はヒラギノやメイリオなどにフォールバックします。コード・数値には等幅書体を使い、文字と情報の役割を分けています。

body {
  color: var(--ink);

    "Helvetica Neue", "Hiragino Kaku Gothic ProN",
    "Noto Sans JP", Meiryo, sans-serif;
  line-height: 1.85;
}
code, output {
  font-family: ui-monospace, SFMono-Regular,
    Consolas, monospace;
}

書体の見え方は端末によって異なります。元ページでは外部Webフォントを読み込んでいません。720px以下ではH2を20pxに調整します。

アイコンとパーツの意味 — UI vocabulary

puzzlesの画面で使う記号と、操作の意味をまとめます。下の記号は説明用の見本です。実際の操作対象は、隣の文字・ボタンの説明・操作ヘルプで確認してください。

見本意味使い方・注意点
＋追加するタブ・項目・作業・プロパティなどを新しく作ります。タブ横ならタブを追加、項目横ならその項目を基準に追加します。アウトラインの行の「＋」は、直後に同じ階層の項目を追加します。
×削除する対応するタブや項目を削除します。タブの「×」はタブ内の内容も削除の対象です。折りたたみや集中の解除とは別の操作です。
×閉じるダイアログの端では「閉じる」を示します。タブ・行・列・プロパティなどの横では「削除」を示すため、ボタンの説明で対象と操作を確認します。
◎選択項目に集中する表示範囲を選択中の作業や関連項目に絞ります。オブジェクト整理では選択項目と関係先、アウトラインでは対象と直下の1階層までを表示します。「集中を解除」で全体へ戻ります。Vim操作の対応キーはoです。
全画面にする四隅を広げた形のアイコンです。編集領域を画面いっぱいに広げます。表示する対象を絞る「集中」とは役割が異なります。対応するツールではfで切り替えられます。
☰補助パネルを開閉する見取り図やオブジェクトなどの補助領域を開いたり閉じたりします。閉じるとメインの作業領域に幅を使えます。パネルを閉じても内容は削除されません。
▸ ▾展開・折りたたみ右向きは閉じた状態、下向きは開いた状態の見本です。子項目やカードの詳細を表示・非表示にします。画面によって▶ / ▼などの形も使います。対応キーはzです。
⠿ドラッグのつまみ押したまま動かし、項目の位置や配置を変更します。アウトラインでは順序・階層を変更し、業務フロー図では未配置オブジェクトをマスへ移します。
↑ ↓ ← →移動・関係の向き操作ボタンでは順序や階層の移動、図の接続線では情報や作業の流れを表します。業務フロー図の実線は作業の流れ・情報の受け渡し、点線は参照・帳票とのやりとりです。
‹ ›前・次へ進むカレンダーでは前／次の月・週、業務フロー図の列では左右への移動に使います。移動する単位は各ボタンの説明に従います。
✓完了を示すタスクが終わったことを示します。アウトラインでは完了／未完了の切り替えに使います。入力位置を示すフォーカスや、編集中の選択状態とは別の状態です。
◆完了予定日を示すカレンダーのタスク帯の終端や完了予定一覧に付けます。作業が終わる予定の日付を表し、実際に完了したことを示す「✓」とは区別します。
↗ / ↓ / ↑リンク先・ページ内の移動資料リンクの「↗」は別資料への移動、「↓」は後の説明へ、「先頭へ ↑」はページ上部への移動を示します。別タブで開くかはリンクの設定によります。

フォーカス・選択・集中を区別する

編集する

フォーカス：いまキーが届く場所

茶色の輪郭は、キーボード操作の対象を示します。Tabなどでボタンや入力欄へ移動し、EnterやSpaceで操作します。入力欄にフォーカスがある間は文字入力を優先し、Escで抜けてからVim操作を使います。

輪郭はフォーカス状態の静的な見本です。ページ上部のコピーボタンでは、Tabキーで実際のフォーカス表示を確認できます。

選択中のタブ

選択：どの作業を対象にするか

選択中のタブは深緑の文字・太字・タブ全体の下辺線で区別します。背景の塗り・外枠・文字の下線は付けません。カードや行の枠・背景は、編集や集中の対象となる項目を示します。別のボタンへフォーカスを移しても、選択対象がそのままの場合があります。

◎ 選択項目に集中

集中：いま見る範囲を絞る

選択項目に表示を絞り、目の前の作業を追いやすくします。集中中の対象と、解除する操作を画面上に示します。見えていない項目のデータは残っています。対象範囲は各ツールで異なります。

共通タブ：outline.htmlのデザインを採用

受注×請求書×＋

タブは編集領域の上に配置します。タイトルと「×」をひとまとまりにし、枠なし・背景なしで並べます。選択中だけ深緑の文字・太字・下辺線を使い、文字の下線は付けません。タイトルで切り替え、「×」で確認後に削除、「＋」で追加します。

静的な見本です。操作ボタンは個別に実装し、削除には対象を含む読み上げ名を付けます。配置と操作の詳細は画面設計のタブの基準を参照してください。

文字付きの部品にも、役割を持たせる

パーツ意味・使い分け
主操作のボタン深緑の塗りと白い文字で、保存や追加など、その場で進める主な操作を示します。削除などの操作は、対象と結果が分かる名前を付けます。
無効なボタン薄い表示で、今は実行できないことを示します。選択対象がない場合の編集など、条件が整うと使えるようになります。
表示切り替え「オブジェクト／関係図／関係一覧」「月／週」など、同じ内容の見せ方を切り替えます。案件やモデルを分ける作業タブとは、切り替える対象が異なります。
読み込み・保存・コピー読み込みはファイルから内容を取り込み、JSON保存はファイルへ書き出し、コピーはクリップボードへ内容を送ります。ブラウザ内の自動保存とは保存先が異なります。
元に戻す・やり直す編集履歴を1段階戻す・戻した編集を進める操作です。対応するツールではu / Ctrl+rを使います。履歴の保存範囲や再読み込み後の扱いは、各ツールのヘルプに従います。

実装時は、アイコンだけのボタンにも「タブを追加」「選択項目に集中」などの操作名を付け、aria-labelで読み上げ名を、必要に応じてtitleで補足を指定します。開閉はaria-expanded、切り替えボタンはaria-pressed、選択中タブはaria-selectedで状態を伝えます。
