01 /

この設計書の使い方・前提

飲料を選び、残高で支払い、受取番号を確認するWeb自動販売機を例にした画面設計書です。画面一覧から見本を開き、利用者ができることを把握してから、情報・表示・操作・結果の詳しい仕様へ進む構成です。

商品選択

商品一覧 → 商品詳細

購入・決済

購入確認 → 支払い → 完了

商品・在庫管理

管理一覧 → 商品編集

この例の前提
項目定義
利用者購入者：ログイン不要のセッション利用。管理者：別途認証済みの管理者ロール。管理者ログイン画面は本資料の対象外。
購入単位飲料1種類を1個。カートや複数個購入は対象外。
通貨・価格日本円・税込整数価格。送料なし。
支払い初期500円のデモ残高。残高追加と実際の決済サービス接続は対象外。
受取購入完了時に受取番号を表示。実機の商品排出・番号照合の設計は別資料で扱う。
サンプル商品DRINK-001 ミネラルウォーター150円・在庫8個。DRINK-002 緑茶180円・在庫0個。いずれも公開中。
資料の位置付け架空サービスの設計例。画面・ボタン・データは説明用で、このHTML自体は購入や保存を実行しない。

仕様の読み分け

オブジェクト定義＝何の情報を持つか

例：商品1件は「商品ID・商品名・価格」を持つ。商品一覧は同じ商品情報のコレクションです。

データ定義＝どこで管理し、いつ変わるか

例：価格は商品マスターで管理する。注文時に金額を保存し、支払い成功時に残高と在庫を更新します。

画面要素は「どこに何を見せるか」、操作・イベントは「操作すると何を行うか」、バリデーション・結果は「実行条件と、その後に何を伝えるか」を説明します。

読み方画面ID（SCR）→ オブジェクト（OBJ）→ 要素ID → 操作ID（ACT）→ 検証・結果ID（VAL / ERR / OK）の順に対応付けます。商品1件は「シングル」、同じ形を持つ複数件は「コレクション」と呼びます。

OBJ-C02 / Order / 注文（シングル）

確定した価格を保存する注文。後で商品価格が変わっても、この注文の金額は変更しません。

Order / 注文（シングル）の要素
要素型・値説明

要素型・値説明

idempotencyKeystring同じ注文の支払要求を識別し、二重引き落としを防ぐキー。サーバー側で注文に紐付け。

データ定義・表示状態・権限

注文・支払いのデータ定義
データ管理場所確定・更新条件制約
PurchaseQuoteサーバーで計算確認画面表示時に再計算。参考値。支払い時にも在庫と残高を再検証
Orderサーバーの注文データ支払い画面へ進む時にpendingで作成。価格はサーバーの商品マスターから確定

Order.statusサーバーの注文データpending → processing → paid または failed。未払いで期限超過ならexpired。paidへの再要求で重複減算しない
処理結果不明サーバーで注文状態照会応答が途切れた場合、同じorderIdを照会。paid確認前に成功表示しない。別注文で再支払いしない

操作・イベント

バリデーション・エラー・成功

購入・決済の検証と結果
ID / 分類条件表示文言処理・復帰
VAL-C01 / 商品確認購入確定前に売り切れ・非公開になったこの商品は現在購入できません。注文作成または支払いを停止。残高を減らさない

VAL-C03 / 価格変更確認画面で表示した価格と注文作成時の最新価格が異なる価格が変更されました。内容をご確認ください。最新金額で確認画面を再表示。同意なしに進めない
VAL-C04 / 期限未払い注文の有効期限を超過支払い期限が切れました。支払い不可。商品選択からやり直す
VAL-C05 / 二重操作同じ注文の連打・再送処理中、または保存済みの支払い結果を表示残高と在庫は1回だけ減らす

ERR-C03 / 確定失敗一括更新が失敗し、paidにならなかった支払いを完了できませんでした。残高・在庫の更新を確定せず、新しい購入確認へ案内

05 /

商品・在庫管理

管理者が商品情報・価格・在庫数・公開状態を更新します。

画面見本・利用者ができること

すべて説明用の静的な見本です。実際の購入・編集操作はできません。

SCR-A01 管理商品一覧

商品の価格・在庫・公開状態を確認し、編集する商品を選べます。

画面要素へ ↓操作へ ↓エラー・成功へ ↓

SCR-A02 商品編集

商品名・価格・在庫・公開状態を変更して保存できます。

画面要素へ ↓操作へ ↓エラー・成功へ ↓

見本で画面の役割を確認した後、下の仕様で情報・データの管理・表示条件・操作・結果を確認できます。

オブジェクト定義

OBJ-A01 / ManagedProduct / 管理商品（シングル）

購入者向けProductに管理用の在庫・公開状態・更新情報を加えたものです。

ManagedProduct / 管理商品（シングル）の要素
要素型・値説明
productId / name / price / imageUrlProductと共通公開画面と同じ商品の基本情報。
stockinteger / 0〜999販売可能な在庫数。
isPublishedboolean公開するかどうか。falseなら購入者向け一覧から除外。
version / updatedAtinteger / datetime同時編集検出用の版と最終更新日時。

OBJ-A02 / ManagedProductList / 管理商品一覧

ManagedProduct[]のコレクション。非公開商品も含めます。

ManagedProductList / 管理商品一覧の要素
要素型・値説明
itemsManagedProduct[]商品ID昇順の全商品。
totalCountinteger管理対象の総件数。

OBJ-A03 / ProductEdit / 商品編集入力

編集画面の入力値と、読み込み時点のversionを保持します。

ProductEdit / 商品編集入力の要素
要素型・値説明
name / price / stock / isPublishedstring / integer / integer / boolean画面から変更する4要素。
versioninteger取得時の版。保存時に一致を確認。
isDirty / fieldErrorsboolean / 要素別メッセージ未保存変更の有無と入力エラー。

データ定義・表示状態・権限

管理用データ定義
データ管理場所更新ルール影響
商品名・価格サーバーの商品マスター管理者が保存時に更新。公開画面の次回取得に反映。作成済みOrderの価格は維持
在庫数サーバーの在庫管理者の在庫更新と購入時の減算で更新。0ならsold_out。負の在庫は不可
公開状態サーバーの商品マスター管理者が切り替え。非公開なら新規購入不可
versionサーバーの商品・在庫管理保存または購入による在庫更新のたびに増加。編集開始後の更新があれば保存を拒否して再取得

共通の表示・操作ルール

共通ルール
観点仕様
画面幅商品一覧はPCで複数列、狭い画面で1列。管理表は横スクロール。設計対象画面の切替幅は680px。
入力とエラー全入力にラベル。エラーは文字で項目直下に表示。保存時に最初の不正項目へフォーカスし、結果通知を読み上げ。
状態の識別売り切れ・処理中・成功・失敗は色だけに依存せず文言で示す。
安全な操作サーバーで権限・金額・在庫・所有者を検証。画面ボタンの無効化だけで制御しない。
時刻・期限注文期限はサーバー時刻で判定。画面は残り時間と期限切れを表示。
