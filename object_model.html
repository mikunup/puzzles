OBJECT MODEL

OBJECT → COLLECTION

オブジェクトを、箱で整理する。

扱う「もの」をオブジェクトの箱にして、名前・プロパティ（持っている情報）・操作（できること）を書き出します。下の段では、1つのオブジェクト、または複数のオブジェクトを組み合わせて、コレクション（一覧）の表示項目と操作を決めます。

01 /

オブジェクト

扱う「もの」ごとに箱を作り、プロパティ（持っている情報）と操作（1件に対してできること）を書き出します。

02 /

コレクション

元にするオブジェクトを選んで一覧を作ります。1つなら単一のコレクション（例：商品一覧）、2つ以上なら組み合わせのコレクション（例：注文 ＋ 商品 ＝ 購入履歴）になります。

オブジェクト整理 ／ オブジェクトとコレクション入力欄で Enter：次の行を追加 ・ 空の行で Backspace：行を削除 ・ 見出しをクリック：開閉
