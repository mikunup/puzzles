OBJECT → COLLECTION

オブジェクトを、箱で整理する。

資料一覧へ ↗
通常モード
01 /

オブジェクト

扱う「もの」ごとに箱を作り、プロパティ（持っている情報）と操作（1件に対してできること）を書き出します。

02 /

コレクション

元にするオブジェクトを選んで一覧を作ります。1つなら単一のコレクション（例：商品一覧）、2つ以上なら組み合わせのコレクション（例：注文 ＋ 商品 ＝ 購入履歴）になります。

矢印は「参照する側 → 参照先」です。ラベルは参照プロパティ名です。コレクションの構成は関係一覧で確認できます。

行＝参照元、列＝参照先。セル内は参照プロパティ名です。件数・多重度は定義されていないため表示していません。

キーボード・編集操作

Esc / 入力欄のEnter：入力を確定して選択項目へ戻る（説明欄のEnterは改行）。入力欄から抜けるとVimキーが使えます。

j / k：次／前の項目 · h / l：参照元／参照先へ
i：オブジェクトを追加 · Shift+i：コレクションを追加 · e：名前を編集 · d：選択項目を削除
z：選択カードの開閉 · o：選択項目と関係先に集中／解除 · f：全画面ON／OFF · v：表示モード切替
t / Shift+t：次／前のタブ · gg / Shift+g：先頭／末尾 · u / Ctrl+r：元に戻す／やり直す

プロパティや操作は各カードの「＋」で追加します。参照型プロパティの参照先を指定すると、関係図と関係一覧へ自動反映されます。Enum型では「＋ 候補」で保存値・表示名を追加し、初期値を選べます。候補の入力は確定時に保存し、空欄・保存値の重複は元の値に戻します。

見取り図と表示設定

オブジェクト整理 ／ オブジェクトとコレクションブラウザ内に自動保存。別の端末へ移す場合は全タブをJSON保存してください。
